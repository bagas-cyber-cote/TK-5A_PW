PRAKTIKUM 3 - PEMROGRAMAN WEB
=============================

Praktikum ini berisi contoh dasar penggunaan PHP, meliputi tipe data,
variabel, konstanta, kutip string, biodata, serta perhitungan harga barang.

DAFTAR FILE
-----------

cek-tipe.php
Menampilkan tipe dan nilai variabel menggunakan var_dump().

biodata.php
Menampilkan biodata mahasiswa, seperti nama, NIM, semester, IPK,
dan status aktif.

Kutip.php
Menunjukkan perbedaan kutip ganda dan kutip tunggal pada string PHP.
Pada kutip ganda, variabel $nama ditampilkan sebagai nilainya; pada
kutip tunggal, teks $nama ditampilkan apa adanya.

hitung-sederhana.php
Menghitung subtotal dan pajak 11% untuk satu jenis barang.

data-barang.php
Menampilkan daftar tiga barang, subtotal tiap barang, jumlah keseluruhan,
pajak 11%, dan total akhir.

Gambar ss\
Berisi tangkapan layar hasil program PHP.

CARA MENJALANKAN
----------------

1. Pastikan Apache pada XAMPP sudah berjalan.
2. Simpan folder Praktikum 3 di dalam C:\xampp\htdocs\TK-A.
3. Buka browser dan akses salah satu alamat berikut:

   http://localhost/TK-A/Praktikum%203/cek-tipe.php
   http://localhost/TK-A/Praktikum%203/biodata.php
   http://localhost/TK-A/Praktikum%203/Kutip.php
   http://localhost/TK-A/Praktikum%203/hitung-sederhana.php
   http://localhost/TK-A/Praktikum%203/data-barang.php

CATATAN
-------

Pada hitung-sederhana.php, nilai total saat ini diatur sama dengan nilai
pajak, dan variabel subtotal kemudian berisi nilai pajak. Karena itu,
hasil yang tampil tidak sama dengan perhitungan subtotal dan total bayar
yang semestinya. data-barang.php menghitung subtotal dan total akhir
secara terpisah.
