PRAKTIKUM 4 - DASAR-DASAR PHP

Folder ini berisi contoh penggunaan operator dan pengolahan data dasar
menggunakan PHP.

DAFTAR FILE
- bandingkan.php    : Membandingkan nilai dengan operator == dan ===.
- gabung-teks.php   : Menggabungkan teks, menghitung panjang teks, dan
                      mengubah huruf menjadi huruf besar.
- hitung-diskon.php : Menghitung potongan harga, harga akhir, dan menguji
                      kondisi harga akhir.
- kalkulator.php    : Melakukan operasi penjumlahan, pengurangan,
                      perkalian, pembagian, dan sisa bagi.
- logika.php        : Menampilkan hasil operator logika AND, OR, dan NOT.
- prioritas.php     : Menunjukkan prioritas operasi serta operator
                      increment (++) dan decrement (--).

CARA MENJALANKAN
1. Pastikan Apache pada XAMPP sudah berjalan.
2. Letakkan folder Praktikum 4 di dalam direktori htdocs.
3. Buka browser dan akses file yang ingin dijalankan, misalnya:
   http://localhost/TK-A/Praktikum%204/kalkulator.php
4. Ganti nama file pada alamat tersebut untuk melihat contoh lainnya.

CATATAN
- Contoh menggunakan data yang ditetapkan langsung di dalam masing-masing
  file PHP; tidak ada input dari pengguna.
- bandingkan.php menunjukkan bahwa == membandingkan nilai, sedangkan ===
  membandingkan nilai sekaligus tipe datanya.
